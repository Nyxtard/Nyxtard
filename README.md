### 🎧 Mi proyecto: NyxVoice

<a href="https://github.com/Nyxtard/NyxVoice">

**[NyxVoice](https://github.com/Nyxtard/NyxVoice)** es una app gratuita para Windows que elimina el ruido de fondo de tu micrófono en tiempo real con inteligencia artificial. Sirve para Discord, Zoom, Meet y OBS, y también limpia audios y videos.
